## My process

### Built with

- Flexbox
- Desktop-first workflow

### What I learned

For this project, I chose to build the layout using a **desktop-first approach**, since I'm more comfortable with that workflow, and then used media queries to adjust the styles for smaller screens (mobile).

```css
@media screen and (max-width: 375px) {
    .box {
        max-width: 327px;
        margin: 0px 24px;
    }
}
```

### Continued development

In future projects, I want to focus on:

- Practicing a **mobile-first approach**, building the mobile layout first and then expanding to desktop, so I can get comfortable with that workflow and compare it with desktop-first.
- Improving my **responsive design** skills to handle a wider range of screen sizes more smoothly.
- Learning **JavaScript** and starting to add interactivity to my projects instead of just static HTML and CSS.
