# Product preview card component

This is a solution to the Product preview card challenge on Frontend Mentor.
## Overview

### The challenge

Users should be able to:

- View the optimal layout for the component depending on their device's screen size
- See hover and focus states for the "Add to Cart" button

## My process

### Built with

- Semantic HTML5 markup
- CSS custom properties
- Flexbox
- Mobile-first workflow

### What I learned

- **Practicing a mobile-first workflow** - I worked more with the mobile layout first, which made it easier to build up styles and then adjust for larger screens using `min-width` media queries.

- **Practicing responsive design** - This project helped me get more comfortable adapting a layout across different screen sizes, going from a stacked mobile layout to a side-by-side desktop layout.

- **Working with Flexbox** - I was able to use Flexbox to lay out the card content and align elements like the price and button.

### Continued development

- **Practicing debugging with DevTools** — I want to get faster at using the browser's DevTools (Computed panel, Flexbox overlay) to diagnose layout issues efficiently.
